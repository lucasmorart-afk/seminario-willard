# Escuela de líderes: V.I.M

Seminario de 15 clases sobre la obra de Dallas Willard, guiado por el patrón VIM (Visión, Intención, Medios). Recurso educativo sin fines de lucro.

Sitio: https://lucasmorart-afk.github.io/seminario-willard/

- `index.html` se genera con `build.py` a partir de los datos de cada clase; no lo edites a mano.
- `textos/`: transcripciones en español publicadas con permiso.
- `fonts/`: Spectral, Literata e IBM Plex Sans Condensed (SIL Open Font License 1.1), servidas desde el sitio para no depender de Google Fonts.

El sitio es estático: no tiene servidor, formularios ni cuentas. El progreso de las pruebas se guarda solo en el navegador de cada estudiante.
